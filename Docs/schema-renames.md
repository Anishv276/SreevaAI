# Schema Rename Reference

This document lists all proposed renames for the Prisma schema — from current names (that are hard to understand) to clearer, beginner-friendly names.

> **Status:** Partially implemented. `OrganizationDetails`, `OrganizationCredentials`, and `Job` (formerly `Organization`, `User`, `Drive`) plus their field renames below have already been applied — see `prisma/schemanames.md` for the as-shipped log. Everything else in this doc (`Application`, `Interview`, `SupportTicket`, `EngineVoice`→`AIVoice`) is still pending.

---

## Model Renames

| Current Model Name | Proposed/Applied Model Name | Status | Reason |
|---|---|---|---|
| `Organization` | `OrganizationDetails` | ✅ Applied | Clarity |
| `User` | `OrganizationCredentials` | ✅ Applied | These are org login credentials, not generic users |
| `Drive` | `Job` | ✅ Applied | "Drive" was internal jargon for a hiring job |
| `EngineVoice` | `AIVoice` | Pending | "Engine" is internal jargon — these are AI voices available in the system |

## Implementation Notes

When applying these renames:
1. Update `prisma/schema.prisma` with all new names
2. Run `prisma migrate dev --name descriptive-field-renames` to push to DB
3. Update all TypeScript files (API routes, `worker.ts`) that reference old field names
4. Update all Python files (`interview/agent_runtime.py`, `interview/agent_persistence.py`, etc.) that query these fields
5. Update any raw SQL queries or JSON key references

> See `CLAUDE.md` for the full list of key files that will need updating.
