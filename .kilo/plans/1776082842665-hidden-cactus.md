# HR Automation Platform - Comprehensive Testing & Debugging Plan

## Product Overview

**Lumoscale.ai / Hirer.ai** - An AI-powered HR recruitment platform built with Next.js 16.

### Tech Stack
- **Frontend**: Next.js 16 (App Router), Tailwind CSS, Framer Motion, Radix UI
- **Backend**: Next.js API Routes, Prisma ORM, PostgreSQL
- **AI Engine**: OpenAI GPT-4o, Python scripts for PDF extraction/scoring
- **Queue System**: BullMQ + Redis for async processing
- **Video/Audio**: LiveKit for AI voice interviews
- **Storage**: Cloudflare R2 (S3-compatible)
- **Email**: Resend API
- **Vector DB**: Pinecone
- **Auth**: JWT-based session management (SignJWT)

### User Roles
- **SUPER_ADMIN**: Platform administrator (manages all organizations)
- **ADMIN**: Organization administrator (HR admin, manages own org)
- **CANDIDATE**: Job applicant
