# HR Automation Platform - Comprehensive Testing & Debugging Plan

## Product Overview

**Lumoscale.ai / Hirer.ai** - An AI-powered HR recruitment platform built with Next.js 16.

### Tech Stack
- **Frontend**: Next.js 16 (App Router), Tailwind CSS, Framer Motion, Radix UI
- **Backend**: Next.js API Routes, Prisma ORM, PostgreSQL
- **AI Engine**: OpenAI GPT-4o, Python scripts for PDF extraction/scoring
- **Queue System**: BullMQ + Redis for async processing
- **Video/Audio**: LiveKit for AI voice interviews
- **Storage**: Cloudflare R2 (S3-compatible)
- **Email**: Resend API
- **Vector DB**: Pinecone
- **Auth**: JWT-based session management

---

## 8-Phase Product Flow

### Phase 1: Drive Creation (Admin creates recruitment drive)
### Phase 2: Job Sharing (Generate/distribute job links)
### Phase 3: Candidate Application (Multi-step form with AI resume extraction)
### Phase 4: AI Screening (Background BullMQ + OpenAI scoring)
### Phase 5: Automated Communication (Email status updates, interview invites)
### Phase 6: Interview Session (LiveKit AI voice interviews)
### Phase 7: Proctoring (Fullscreen monitoring, behavioral tracking)
### Phase 8: Grading & Reporting (HR dashboard for final decisions)
