PROBLEM PATTERN
================================================================================

❌ CURRENT (WRONG) — Deleted records included:
   SELECT COUNT(*)::INT FROM "Drive"

✅ CORRECT (FIXED) — Deleted records excluded:
   SELECT COUNT(*)::INT FROM "Drive"
   WHERE "isDeleted" = false

For complex JOINs, add "isDeleted" = false to every table:
   FROM "Organization" o
   JOIN "Drive" d ON d."orgId" = o.id
   WHERE o."isDeleted" = false AND d."isDeleted" = false

ROOT CAUSE ANALYSIS
================================================================================

Why This Happened:
  • Soft-delete mechanism implemented via Prisma middleware
  • Middleware auto-filters ORM operations (findMany, count, etc.)
  • But middleware does NOT filter raw SQL ($queryRaw)
  • Developers may not know about middleware limitations
  • No linting rules to catch missing filters in raw SQL
  • No code review checklist for raw SQL queries

Prevention:
  1. Add ESLint rule: flag raw SQL without isDeleted check
  2. Update code review template: "Does this query filter soft-deletes?"
  3. Add test coverage: verify deleted records are excluded
  4. Update CLAUDE.md: document soft-delete patterns
